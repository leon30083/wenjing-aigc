# 应用图标说明

请将您的应用图标（256x256 或更高分辨率的 .ico 格式）放置在此目录下，并命名为 `icon.ico`。

## 图标要求

- **格式**: Windows ICO (.ico)
- **尺寸**: 256x256 或更高
- **名称**: icon.ico
- **位置**: build/icon.ico

## 生成图标工具

您可以使用以下工具将 PNG 转换为 ICO：

1. **在线工具**:
   - https://www.icoconverter.com/
   - https://convertio.co/png-ico/

2. **命令行工具**:
   - ImageMagick: `magick convert icon.png -define icon:auto-resize=256,128,96,64,48,32,16 icon.ico`
   - png2ico: `png2ico icon.ico icon.png`

## 临时方案

在获得正式图标前，您可以：
1. 使用任何现成的 .ico 文件作为占位符
2. 或者暂时注释掉 electron-builder.yml 中的 `icon: build/icon.ico` 行
